# LIDMAS Auto Limited - Official Website

Premium car dealership website for LIDMAS Auto Limited, Nairobi, Kenya.

## Features
- Responsive vehicle inventory with search & filters
- Vehicle comparison tool
- Financing calculator
- Trade-in value estimator
- Test drive booking with WhatsApp integration
- Customer reviews & testimonials
- Local SEO optimization (Google Business, schema markup)
- 12-month warranty information
- Multi-section parallax design

## Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- SEO: JSON-LD Schema, Open Graph, Geo tags
- Deployed on Netlify
